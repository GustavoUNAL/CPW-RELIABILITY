# Acordionero (Pad 4)

Misma forma que Costayaco. El código de campo es `ACORDIONERO`.

| Carpeta | Contenido |
|---|---|
| `operacion/AAAA-MM/` | Reporte de generación diario |
| `operacion/pruebas/AAAA-MM/` | Pruebas de carga |
| `GTE/AAAA-MM/` | Data Soporte e indicadores |
| `fallas/AAAA-MM/AAAA-MM-DD_EQUIPO_RFxx/` | FO-GE-033, logs, evidencias y análisis |
| `mantenimiento/sabana/AAAA-MM/` | Sábana y programación |
| `mantenimiento/condicion/` | Vibraciones y válvulas |
| `inventarios/` | Repuestos Jenbacher |
| `informes/AAAA-MM/` | Informe publicado, con sus fotos y el HSE del deck |

`concertacion/` se abre cuando llegue el consolidado de horas del campo.
